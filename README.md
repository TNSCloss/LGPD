# Portfólio LGPD — Programa de Privacidade do Supermercado 10

**Encarregado de Dados (DPO) · LGPD · Privacidade por Design**

Um programa completo de conformidade com a **Lei Geral de Proteção de Dados (LGPD — Lei 13.709/2018)**, construído para o caso fictício de uma rede de supermercados (**Supermercado 10** — 15 lojas, ~1.200 colaboradores, e-commerce e app), com todos os documentos prontos para adaptação a qualquer organização.

</div>

---

## Sobre este portfólio

Cada pasta demonstra **uma competência específica** de um programa de privacidade — da fundação documental à execução operacional. Todos os documentos se conectam: o RoPA referencia os LIAs, os LIAs sustentam as bases legais da matriz, o RIPD avalia o alto risco, e o playbook responde quando algo dá errado.

## Estrutura e o que cada pasta prova

| Pasta | Entrega | Competência demonstrada |
|---|---|---|
| [01-ropa-registro-de-atividades](Github/LGPD/01-ropa-registro-de-atividades/README.md) | RoPA (Art. 37) — planilha `.xlsx` + markdown · 5 processos (RH, Marketing, Vendas, Financeiro, TI) | Mapeamento de fluxos de dados |
| [02-ripd-relatorio-de-impacto](Github/LGPD/02-ripd-relatorio-de-impacto/README.md) | RIPD/DPIA de **alto risco** — reconhecimento facial (biometria, Art. 11) | Análise de risco e proporcionalidade (Art. 38) |
| [03-lia-teste-de-legitimidade](Github/LGPD/03-lia-teste-de-legitimidade/README.md) | 2 LIAs completos — prevenção à fraude e marketing direto (4 etapas) | Interesse legítimo bem fundamentado (Art. 10, §3º) |

| [06-gestao-de-direitos-do-titular](Github/LGPD/06-gestao-de-direitos-do-titular/README.md) | Fluxo DSAR (15 dias), formulário, 7 templates, matriz de identidade | Atendimento de direitos (Art. 18) |
| [07-contratos](Github/LGPD/07-contratos/README.md) | DPA operador (Art. 39), confidencialidade, cláusula de transferência internacional | Gestão da cadeia de terceiros |
| [08-governanca](Github/LGPD/08-governanca/README.md) | Matriz de bases legais, gap analysis ANPD (antes/depois), comitê, treinamento | Governança e medição |
| [09-canal-do-encarregado](Github/LGPD/09-canal-do-encarregado/README.md) | Página web do canal do titular + política de cookies com mapa | Comunicação com o titular (Art. 41) |
